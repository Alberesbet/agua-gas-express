AGUA & GAS EXPRESS — VERSAO 3.1 (CORRECAO DO FLUXO DE PEDIDOS)

O que foi corrigido no codigo:
- Restaurada a lista de produtos na tela do cliente, com nome, preco e botoes +/−.
- A tela mostra um aviso claro se o catalogo ainda nao tiver sincronizado.
- A Administracao republica o catalogo local se a configuracao remota estiver sem produtos.
- O botao FAZER PEDIDO agora so confirma o pedido depois que o Firestore aceitar a gravacao; em caso de falha, mostra erro e mantem as quantidades para tentar novamente.
- A conversa acompanha a autenticacao anonima; o listener e recriado quando o UID fica disponivel.
- O arquivo firestore.rules inclui permissao explicita para a subcolecao orders/{orderId}/messages/{messageId}.

PASSO NECESSARIO PARA O CHAT FUNCIONAR:
O codigo do aplicativo nao consegue publicar sozinho as regras no Firebase Console. No Firebase Console do projeto agua-e-gas-express, abra Firestore Database > Regras e publique regras que incluam a subcolecao messages. Para um TESTE entre os aparelhos, o modelo do arquivo firestore.rules e:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /orders/{orderId} {
      allow read, write: if request.auth != null;
      match /messages/{messageId} {
        allow read, write: if request.auth != null;
      }
    }
    match /appConfig/{configId} {
      allow read, write: if request.auth != null;
    }
  }
}

IMPORTANTE: estas regras sao permissivas e servem apenas para teste controlado. Qualquer pessoa que consiga autenticar no aplicativo pode acessar dados compartilhados. Antes de uso comercial com clientes reais, e necessario implementar regras de producao que separem clientes e autorizem a Administracao de forma segura.
